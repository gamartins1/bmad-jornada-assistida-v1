# Skill — Testing

## Objetivo
Garantir cobertura técnica e funcional.

## Workflow
1. Ler história.
2. Mapear critérios de aceite.
3. Verificar unitários/integrados existentes.
4. Identificar lacunas.
5. Criar/ajustar testes automatizados.
6. Preparar cenários manuais DADO/QUANDO/ENTÃO.
7. Consultar playbooks de massa/by-pass.
8. Definir evidências.
9. Avaliar regressão.

## Ferramentas
- Jest
- Cypress
- TAAC
- Sonar
- IUQuali
- OBS Studio
- SharePoint

## Guardrails
Não criar testes manuais que apenas dupliquem automação sem benefício.
