# Skill — Development

## Workflow
1. Ler história.
2. Ler KB.
3. Identificar componentes.
4. Ler padrões do repo.
5. Fazer plano.
6. Validar plano.
7. Implementar.
8. Criar testes.
9. Executar testes.
10. Self-review.
11. Aguardar code review.
12. Criar PR quando autorizado.

## Regras
- Trabalhar somente nos repos fornecidos.
- Não criar repos.
- Seguir padrão local quando KB não cobrir.
- Não introduzir lógica de modalidade/segmento em Building Block sem justificativa.
- Atualizar artefatos auxiliares aplicáveis.
