# Skill — Discovery

## Objetivo
Estruturar problema, objetivo, escopo, dependências e perguntas abertas.

## Inputs
Context Pack + demanda + inception/showcase quando disponível.

## Outputs
Discovery summary com:
- problema;
- objetivo;
- escopo;
- fora de escopo;
- squads;
- dependências;
- riscos;
- perguntas abertas.

## Human gate
PM valida objetivo/escopo funcional.
