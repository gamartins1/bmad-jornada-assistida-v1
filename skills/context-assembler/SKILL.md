# Skill — Context Assembler

## Objetivo
Montar o contexto necessário para uma demanda antes de discovery, story ou implementação.

## Inputs
- demanda;
- Knowledge Base;
- repos fornecidos;
- repo de referência;
- desenho de solução;
- artefatos disponíveis.

## Outputs
Context Pack com:
- produto;
- segmento;
- modalidade;
- jornada;
- regras relevantes;
- ownership;
- componentes;
- repos;
- dependências;
- padrões;
- decisões;
- testes relacionados.

## Guardrails
- Não inventar repos.
- Não assumir ownership ausente.
- Sinalizar informação faltante.
- Não alterar código.
