# Skill — Technical Refinement

## Objetivo
Analisar impacto e construir plano de implementação.

## Inputs
- história aprovada;
- Context Pack;
- arquitetura;
- repos;
- repo de referência.

## Outputs
- impact analysis;
- componentes/repos afetados;
- estratégia;
- plano de implementação;
- testes;
- infra;
- documentação;
- artefatos auxiliares como Bruno.

## Guardrails
- Não criar repo.
- Não assumir padrão de API existente.
- Alertar violação de agnosticidade de Building Block.
- Alertar quando alteração shared exigir regressão.

## Human gate
Dev/Tech Lead validam plano conforme impacto.
