# Skill — Release

## Objetivo
Preparar artefatos para produção.

## Inputs
- história;
- PR;
- mudanças;
- testes;
- evidências;
- infra;
- arquitetura;
- template HTML.

## Outputs
- informações para GMUD por repo;
- playbook;
- plano de validação produtiva;
- rollback e critérios.

## Regras
- GMUD é por repo.
- Dashboard Datadog é obrigatório.
- Validar pré-requisitos e janela.
- Não declarar GMUD aprovada sem evidência do ServiceNow.
