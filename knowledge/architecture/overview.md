# Architecture Overview

iClientes → 360i → JU9 Journey → KF6 Building Blocks → BFFs → Product APIs / shared services.

## Contas

- JU9: jornada.
- KF6: Building Blocks.

## Princípios

- Jornada é o chassi.
- Building Blocks isolam etapas.
- BFF adapta contratos para frontend.
- APIs backend realizam integrações mais pesadas.
- Regras específicas de modalidade/segmento devem permanecer na jornada sempre que possível.
- Building Blocks devem ser agnósticos.
