# Terminology

| Termo | Significado |
|---|---|
| Portabilidade | Trazer contrato de outro banco |
| Banco origem | Banco onde o contrato está atualmente |
| Convênio | Órgão/empregador público |
| Processadora | Entidade que atende um ou mais convênios |
| Margem | Capacidade mensal de comprometimento consignável |
| Saldo devedor | Valor para liquidar o contrato hoje |
| Averbação | Comprar a dívida/incluir como ativo sob responsabilidade do banco |
| Desaverbação | Processo contrário |
| Oferta | Máximo possível oferecido |
| Simulação | Cálculo dentro de range mínimo/máximo |
| Troco | Valor adicional no refinanciamento de portabilidade |
| Modalidade 3 | Portabilidade sem troco |
| Modalidade 5 | Refinanciamento de portabilidade com troco |
| Modalidade 8 | Retenção |
| Jornada assistida | Gerente executa a jornada para o cliente |
| Jornada digital | Cliente se autoatende no SuperApp |
| Building Block | Microfrontend + BFF que isola uma etapa da jornada |
| JU9 | Prefixo/conta da jornada assistida |
| KF6 | Conta dos Building Blocks |
| Caronte | Proxy reverso entre frontend e BFF |
