# Release & Production

## GMUD

GMUD é por repositório. Uma história pode ter múltiplas GMUDs.

## Playbook

Deve conter:

- GMUD/CHG;
- data;
- janela;
- alteração;
- componentes;
- responsáveis;
- procedimento;
- validação;
- dashboard Datadog;
- rollback;
- critérios de rollback.

## Produção

Validação normalmente manual.

Call gravada com PM, Tech Lead, dev e Group Tech Manager I.

A call acompanha esteira, explica playbook e executa validação funcional.

Link da gravação é evidenciado na GMUD.
